# Cologne Dupe House

A polished starter storefront for an inspired-by cologne brand.

## Highlights

- Elegant, responsive storefront with glassmorphism visuals
- Advanced product controls: collection, search, max price, sorting, and reset
- Interactive cart panel with quantity stepper controls
- One-click demo mode to auto-run a guided interaction flow
- Light/dark theme toggle with persisted preference
- Subtle transitions and UI feedback via card motion + toast notifications

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.
